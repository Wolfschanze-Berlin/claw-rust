## Learnings by Category

### Mistakes (M)
- Team shutdown can hang with idle agents — manual cleanup of `~/.claude/teams/` required as fallback

### Good Decisions (G)
- Treated user's immediate pivot (Next.js → egui-only) as source of truth without trying to reconcile
- Spawned agents with opposing perspectives (technical + UX + critical) for productive tension
- Used structured choice points (2-3 dimensions × 2-3 options) to converge quickly
- Framed architectures as narratives with personality (risk profile, complexity story)
- Devil's advocate successfully challenged premature trait abstraction (YAGNI)
- UX researcher proposed channel state machine — immediately implementable bridge between UX and code

### Patterns (P)
- Specify concrete async primitives (mpsc, broadcast, tracing::Layer) not abstract "event system"
- Target 2-4 hour scope per GitHub issue; use epic for narrative, issues for tasks
- Add refinement loop after initial user choice (propose → choose → challenge → refine)
- Enforce role boundaries in multi-agent teams — each contributes from their domain only
- Hybrid architectures optimize for learning, not purity

### Debugging (D)
- Design quality (structured choices, YAGNI, concrete primitives, granular issues) may predict fewer implementation bugs — hypothesis to validate during #33-#42

### Architecture (A)
- Defer implementation until architecture is agreed; prototyping too early locks in accidental decisions
